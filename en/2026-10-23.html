Gergely Orosz @GergelyOrosz

  • 软件工程溢价从哪来：他说很多人忘了，软件工程师比机械电气土木化工挣得多、能远程、福利更好，核心原因是这行变化太快，愿意快速学新技术和新方法的人更少，过去大概有 10 到 20 年相对稳定，于是大家忘了溢价从哪来，AI 只是又一轮技术浪潮，能掌握的人会更好过 原帖
  • 不爱学新东西就等于退出：他接着说如果你不喜欢学新东西，甚至不愿学和自己原先看法冲突的东西，那你其实已经在有意无意离开这个行业，他特别敬重 Kent Beck，当作终身学习的榜样 原帖
  • 夸 Grok Bot 也吐槽：他说 Grok Bot 团队发货极快，而且是唯一在欧盟正式上线的大平台助手，Meta Muse 和 OpenAI Dots 在欧英都不可用，不过管理 connectors 的界面一度被拿掉，他又抱怨了一通 原帖

看法：他把「AI 冲击」落回职业基本面，溢价来自持续学习，不是来自岗位名称

Pieter Levels @levelsio

  • VPS 赶紧藏起来：他说现在到处在被黑，有 VPS 的人尽快把机器从公网收进 Tailscale，再用 Cloudflare Tunnel 对外，SSH key 挡不住漏洞和利用 原帖
  • 两个都免费：有人担心依赖公司，他说 Tailscale 基于开源 WireGuard，也可以让 AI 直接帮你搭，而且 Cloudflare Tunnel 和 Tailscale 对个人都免费，靠企业加购赚钱 原帖 WireGuard 补充
  • 昨天 PHP，今天 Ruby：有人说只有「软语言」才会中招，他回今天轮到 Ruby 了，上游爆出多个 10.0 严重漏洞，GitLab 那波问题也追到了 Ruby 本身 原帖

看法：实操建议比骂语言有用，AI 挖洞时代所有暴露在公网的老软件都要假设会被翻一遍

Guillermo Rauch @rauchg

  • 杀掉静态凭证：他转 Vercel 的行业呼吁，调查 1000 多家 SaaS 里只有 8.4% 支持安全认证，主张用短命 OIDC 令牌取代长期密钥，像当年一起推 TLS 绿锁一样 原帖
  • 本周吐槽：说你阿姨的密码是厨房便利贴上的 P4ssword，而守护互联网加密的人密码是「4」，这把钥匙能用来瞄准和解密几乎一切，残余风险还在清理 原帖
  • Agent 把软件撕成两极：一边是深后端，一边是即时前端，Ship 上讲了托管后端和 agent 的积木，tmp.now 临时部署连注册都省了，agents 可以随时丢上线 原帖
  • 面试变了：有人说五年前不会写 debounce 挂了面试，他回现在更重要的是懂 debounce 这个概念，在概念空间里导航的能力已经比写代码本身更重要 原帖
  • Generative UI 例子：夸 TakoViz 接进 AI Gateway 后，AI 搜索不再只吐长文，能直接给出股票天气体育等可操作的数据组件 原帖

看法：安全叙事和产品叙事绑在一起，临时部署是给 agent 用的，OIDC 是给人类和机器共用的

Ethan Mollick @emollick

  • Opus 4.8 打赢人类审稿人：一项覆盖 124 篇哈佛社科论文的研究里，Opus 4.8 在各项指标上胜过人类专家同行评审，他说学界必须尽快想清楚怎么让科学流程适应 AI 原帖
