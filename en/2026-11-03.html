  • AI 采用率还在涨：Simon Willison 更新美国人口普查局企业 AI 采用率图表时发现，统计口径被那份 Super Intelligence 行政令改动过，Mollick 转引时强调采用率仍在增长，去年夏天的采用率下滑说法站不住 原帖 Simon
  • Opus 5.5 一句话做项目：他让 Opus 5.5 做了一个网站，能看美国每个城市最快的进城路线、哪里最适合碰头、大城市的通勤流域，又只用一句 prompt 让它把一个科幻短篇拍成短片 原帖 短片

我的看法：Mollick 的价值在于提醒大家去更新对模型的旧印象，权重编辑这条值得持续盯复现进展

Pieter Levels @levelsio

  • Battlefield 1942 上网页：他用 Claude Code 反编译了 Battlefield 1942 免费试玩版的 C 引擎，移植到 WASM 并加上多人联机，比之前移植 Quake、DOOM 难得多，服务器 16 人上限当晚就满了，第二天又跑通了有飞机的 Wake Island 地图 原帖 Wake Island
  • 成本账：整个反编译和移植大约用了 100 万 output token，按 API 价约 100 美元，而他只付 Claude 每月 100 美元订阅，订阅制对重度用户的补贴很明显 原帖
  • MCP 和 API 之争：朋友 Steve Lacey 说自己的 agent 有 MCP 也几乎不用，更爱直接拿 .env 里的 key 调 API，levelsio 一直觉得 MCP 和 API 本质差不多，长期会合流 原帖
  • X 不适合买推广：回应 Lulu Cheng Meservey 关于付费互动逆向选择的观点，他说 X 更像一个大论坛而不是观众席，直接坦诚才是价值所在，所以最有影响力的人恰恰买不到 原帖

我的看法：游戏移植是很好的 agent 能力展示，成本那笔账比 demo 本身更值得看
